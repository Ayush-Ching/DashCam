This is an endless runner that can be controlled by physically jumping, sliding and changing lanes in front of the webcam.

An alternate (more difficult) keyboard only mode is also available. In the keyboard mode, you can use WASD and Arrow keys to control the character.

Use the escape key to pause and access the settings panel.

It uses [MediaPipeUnityPlugin](https://github.com/homuler/MediaPipeUnityPlugin)
